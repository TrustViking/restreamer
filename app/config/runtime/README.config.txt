Папка config/ — пользовательские конфиги приложения.

Что лежит здесь:

  app_config.yaml          обязательно
    Основной конфиг приложения: пути, режимы обработки, лимиты LLM,
    параметры публикации. Если файл отсутствует при старте, приложение
    создаст его автоматически из bundled-копии внутри _internal\.
    Можно править вручную в любом текстовом редакторе.

  app_config.example.yaml  публичный пример
    Пример с пустыми/нейтральными значениями. Используется как шаблон
    при первичном развёртывании или для сравнения с вашей версией
    после обновления.

  templates.yaml           обязательно
    Шаблоны промптов LLM и формата публикаций Telegram/Google Docs.
    Менять можно, но осторожно: ломкие изменения сломают merge.

Переопределение пути к app_config.yaml:
  Переменная окружения APP_CONFIG_PATH (если задана) указывает на
  альтернативный файл. Иначе используется config\app_config.yaml
  рядом с broadcaster.exe.
